# Strang Hinglish Notes

This folder has the chapter-wise Hinglish conversion/notes for the local Strang linear algebra PDF.

## Files

- `Strang-Linear-Algebra-Hinglish-Notes.md`
  Full chapter-by-chapter Hinglish notes in one file.
- `chapters/`
  Same notes split into separate chapter markdown files.
- `visuals/`
  Chapter-wise visual galleries with representative figures extracted from the PDF.
- `assets/strang/`
  The actual extracted image files used by the galleries.
- `../chapter-extracts/`
  Raw chapter-wise text extracted from the PDF so nothing is lost from the source structure.

## How to Use

1. Open the original PDF.
2. Open the matching chapter section in `Strang-Linear-Algebra-Hinglish-Notes.md`.
3. If you want visuals, open the matching file in `visuals/`.
4. Read the Hinglish notes first.
5. Then solve the examples and review problems from the original PDF or the raw chapter extract.
